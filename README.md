# 🐰 토끼 마을

나만의 토끼를 꾸며서 3D 마을을 깡총깡총 돌아다니는 브라우저 게임이에요.

## 플레이 방법
- **이동**: W A S D 또는 방향키 (휴대폰은 왼쪽 아래 조이스틱)
- **점프**: Space
- **타입 기술**: F
- **시점 돌리기**: 화면 드래그 / 확대·축소: 휠 또는 두 손가락
- **채팅**: Enter

## 토끼 꾸미기
털 색, 무늬(민무늬·더치·샴·점박이·마스카라), 무늬 색, 눈 색, 타입(풀·땅·물·불·신앙)을 고를 수 있어요.

## 기능
- 들판에 떠 있는 당근 모으기
- 낮·밤이 바뀌는 하늘 (밤에는 반딧불이와 별)
- 이웃 토끼들과 대화, 인사, 하트
- 타입별 기술: 꽃피우기, 굴 파기, 물장구, 불꽃, 기도
